# 飞絮治理施工资料系统（DB11/T712 C类）

北京园林杨柳飞絮综合治理工程 **施工资料（C类）** 管理系统，严格遵循
`DB11/T712-2020 园林绿化工程资料管理规程`，覆盖六大工艺：树干注射抑絮剂、
高压喷水降絮、树冠修剪、地面清扫、雌株高接改造、老树伐除更新。

## 功能
- 多人登录（资料员 / 项目经理 / 监理 / 管理员）
- 12 张 DB11/T712 标准表单内置，开箱即用；支持自定义表单
- 动态填报 + 必填校验
- 报验状态机：交底 → 施工 → 自检 → 报验 → 验收（禁止跳步）
- 八册组卷视图（C1~C8）
- Word 导出：上传含 `{{字段key}}` 占位符的 docx 模板套用本单位格式，
  或无模板时自动生成两列表格

## 运行
```powershell
pip install -r requirements.txt
python run.py
```
浏览器访问 http://127.0.0.1:5000 ，默认账号 `admin / admin123`。

## 目录
```
app/
  __init__.py    应用工厂
  constants.py   四阶段/六工艺/八册/报验状态机枚举
  models.py      数据模型
  auth.py        登录注册
  views.py       项目/模板/填报/报验/导出
  export.py      Word 导出引擎
  seed.py        管理员 + 标准表单初始化
  templates/     页面
config.py        配置
run.py           启动入口
```
数据库与运行时文件位于 `instance/`（不入库）。
